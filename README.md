# Amperstrand/.github

Org-level REUSABLE WORKFLOWS only. GitHub requires org workflows to live
here (consumed via `uses: Amperstrand/.github/...`).

All other ops content — tooling, practice docs, lessons, session
blueprints — lives in [Amperstrand/amperstrand-ops](../amperstrand-ops)
(the single ops home).

## Workflows

- `rust-embedded.yml` — shared embedded Rust CI (from amp-embedded-common)
- `gitleaks.yml` — org-wide secret scanning (pinned binary, full history)
